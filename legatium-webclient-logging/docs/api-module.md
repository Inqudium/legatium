# Module legatium-webclient-logging

Auto-configured `WebClient` exchange filter for Spring Boot applications
that logs one structured `client_*` line per outbound HTTP exchange. The
field-and-configuration-identical RestClient/RestTemplate twin is
`legatium-restclient-logging`; the long-form guide, including the deliberate
stack differences, lives in
[docs/GUIDE.md](https://github.com/Inqudium/legatium/blob/main/legatium-webclient-logging/docs/GUIDE.md).
